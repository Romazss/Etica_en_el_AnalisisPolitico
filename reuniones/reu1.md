# etica

Resumen

### Objetivo del Proyecto

- El grupo debe desarrollar un proyecto sobre un caso sociotécnico real vinculado a la ética de la IA.
- Se decidió explorar el tema de ética en análisis político en redes sociales.
- El trabajo consiste en crear un póster científico con presentación oral de 10 minutos.
- El grupo debe asumir una postura ética central clara desde el inicio.

### Enfoque Temático Propuesto

- Análisis de la polarización política en redes sociales y cómo los algoritmos la fomentan.
- Investigación sobre la propagación de información falsa en redes sociales durante eventos políticos.
- Pregunta ética propuesta: "¿Cómo investigar desinformación sin reproducir desinformación?"
- Alternativa: "¿Dónde está el límite ético entre monitorear opinión pública disponible y manipular/perfilar votantes?"

### Aspectos Técnicos Discutidos

- Uso de scraping y bots para recolección de datos de redes sociales.
- Posibilidad de utilizar API Key de Meta para acceder a datos de Instagram de forma legal.
- Experiencias previas de participantes con scraping en diversas plataformas.
- Consideraciones sobre el manejo de captchas y limitaciones técnicas.

### Organización del Trabajo

- Se creó un repositorio público en GitHub para el proyecto.
- Estructura propuesta: carpetas para documentación, análisis e informe.
- Se utilizará LaTeX para la elaboración del póster científico.
- Se prefiere trabajo modular pero colaborativo para mantener coherencia.

### Cronograma

- Fecha de entrega para el grupo: 17 de noviembre.
- Presentación: 24 de noviembre.
- El grupo reconoce que están ajustados de tiempo.

### Postura Ética en Desarrollo

- Los algoritmos de redes sociales fomentan la polarización política.
- Esta polarización limita el diálogo político, fomenta la desinformación y reproduce sesgos.
- Se debe considerar la confidencialidad de datos al realizar análisis.
- Preocupación por el impacto real que tienen las inferencias hechas con grandes volúmenes de datos.
