- **Plataforma Telar**: Análisis desinformación proceso constituyente

- **El Desconcierto & CNN**: Casos bots y fake news

### Secciones principales:

1. **Postura ética central** - Tesis principal del proyecto
2. **Análisis sociotécnico** - Mecanismos de algoritmos, datos contexto chileno
3. **Casos chilenos 2021-2025** - Elección, plebiscitos, campañas actuales
4. **Actores y dinámicas de poder** - Quiénes controlan, cómo manipulan
5. **Análisis ético** - Riesgos documentados
6. **Propuestas viables** - Soluciones regulatorias (modelos UE, Brasil, Chile)
